# EaserRagInteract
一个企业级RAG智能体平台，围绕智能文档检索与问答场景，提供多路检索引擎、意图识别、问题重写、会话记忆、MCP工具调用等核心能力。系统采用多模型路由与熔断降级机制，支持高并发场景下的稳定服务。通过分布式队列限流和全链路追踪，保障系统在并发下的可用性与可观测性。
技术架构：SpringBoot、MyBatis Plus、PgVector、Redis、Redisson、Tika、Sa-Token、RAGAS、MCP。
1. 智能意图路由：基于LLM构建意图识别树，覆盖知识库问答、MCP工具调用与系统指令；低置信度自动澄清反问，Top-1准确率 90%+。	集成MCP协议，按意图路由工具、LLM自动提参，支持多工具并行调用，打通知识检索与外部系统。
2. 混合检索引擎：基于多路检索实现「意图定向+全局向量」双路召回，多线程并发执行，配合去重与重排序后处理。Top-1相对传统RAG，	召回命中率提升28.5%，过度检索率降至10%以内，上下文精准度提升20.5%，平均首字响应7秒内。
3. 查询理解与记忆治理：基于LLM实现问题重写与子问题拆分，支持多轮上下文补全与复杂问题并行子查询，结合术语归一化与规则兜底，	Recall@1 提升 18.8%。设计滑动窗口 + LLM 摘要压缩的会话记忆机制，超阈值自动摘要并持久化至PostgreSQL，有效控制长对话Token 	成本。
4. 分布式流量治理基于：Redis信号量+ZSET+Pub/Sub实现分布式排队限流，Lua脚本保证原子性，支持公平排队与超时拒绝，SSE实	时	推送队列状态，避免突发流量压垮模型服务。
5. RAG质量评测闭环：搭建基于RAGAS的端到端评测体系，覆盖检索、延迟、回答质量三大维度 20+指标，支持A/B Diff对比与人工校正，	驱动答案忠诚度（faithfulness）+10.3%、答案相关性+8.0% 等关键指标持续迭代。
